# DA S15 — Dashboard and presentation

## Start here

Use your own DA learner ID from your roster. Sign in to upload with the Google account registered with the lecturer. If you need account or file help, read STUDENT_HOW_TO.md supplied with the student materials. A repository is a folder of saved project files; an upload form is where you hand in assessed work. Saving to a repository does not submit an assignment.

## Do the work

1. Use the Power BI lab walkthrough before this capstone. Windows: obtain Power BI Desktop from https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-get-the-desktop. Mac: use the lecturer-provisioned browser workspace, already tested with your authorised teaching account, or a prepared Windows lab computer. A personal Gmail account is not a substitute for workspace access. Do not buy a licence or start a trial to unblock class.
2. Load the five CSV tables into ONE model, set types, build the relationships, date table and three measures in lab_powerbi.md. Reconcile the totals before designing visuals. Save your .pbix locally or save the browser report in the designated workspace.
3. Create the required one-page dashboard, capture readable visuals with visible filters, and write the question, numerical answer, supporting evidence and what would change your recommendation.
4. Build a short PowerPoint presentation for the five-minute explanation. Put your narration in slide notes. Include the model/relationship evidence, measure formulas as text, dashboard evidence and recommendation.
5. Complete all five S15CHECK lines from NUMERICAL_EVIDENCE.md using values read from your own model. Include them as plain text in slide notes or a DOCX/PDF appendix; screenshots alone cannot supply those values.

## Check and submit

Upload PPTX with narration notes and, if the written evidence is separate, its DOCX or selectable-text PDF. Include all requested numerical evidence in that upload set. Keep the PBIX or authorised report link as supporting project material and give the link in your evidence document. The upload form does not accept PBIX or ZIP. Check the five filter contexts and the distinction between delivered revenue before returns and net revenue.

## How to hand in

Open the correct cohort/assessment form below and read its current deadline. Fill the required identity fields; leave Team ID blank for individual work. Choose Add file > Upload and select the complete required file set. Wait for the filenames to appear, then click Submit. Keep the confirmation page and local copies. Each file must be at most 10 MB. If replacing work before the deadline, send the complete set again; the latest on-time response replaces the earlier response. If the form is closed or upload fails, keep your files and contact the lecturer; do not use a different assignment form.
