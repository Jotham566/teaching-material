# DA S05 — SQL analysis

## Start here

Use your own DA learner ID from your roster. Sign in to upload with the Google account registered with the lecturer. If you need account or file help, read STUDENT_HOW_TO.md supplied with the student materials. A repository is a folder of saved project files; an upload form is where you hand in assessed work. Saving to a repository does not submit an assignment.

## Do the work

1. Install DB Browser for SQLite from https://sqlitebrowser.org/dl/ using the Windows or macOS installer for your computer, or use the prepared lab installation. It is a desktop application, not a website account; no database account is needed.
2. Copy the supplied riverside.db into your session folder, open DB Browser, choose Open Database and select that copy. Choose Execute SQL. Follow the SQL lab examples before building the assessed query.
3. Build the 2025 Delivered report, net of returns, with one row per rep/month. Return columns in this order: region, rep_name, month, gross_ugx, returned_ugx, net_ugx. Use rep region, retain walk-in orders and combine multiple return events before joining.
4. Run your query using the Execute button. Check there are no duplicate rep/month keys, all months are in 2025, and net equals gross minus returns. Add a SQL comment identifying a rep to discuss and why; the discussion is formative.
5. Save the SQL text from the Execute SQL editor as your learner ID followed by _S05.sql. If using a text editor, save plain text with a .sql extension, not .sql.txt. Reopen the file and execute it against the issued database.

## Check and submit

Submit exactly ONE .sql file containing the final report query, optionally with comments beginning --. Do not submit the database, CSV result, screenshot or the entire lab exercise. Marks: row keys 25, gross 25, returns 25, net 25; amount tolerance is 1 UGX after rounding.
