EXPLAIN IN ORDINARY WORDS
A function is a named set of instructions. def defines it; a call runs it with inputs. Parameters are input names, arguments are supplied values, and return sends the result back.

CHECK AND EXPECTED ANSWER

DISCUSSION KEY FOR THIS SLIDE
ANSWERS
How did you do?
A
"The Eastern region is underperforming"
A number, a population and a window. Underperforming on what measure, against which comparison, over what period. As it stands it is a conclusion with no question underneath it.
B
Two answers to "how many customers"
Everyone in the customers table, which is 401 here, or everyone who placed an order in a given window, which is smaller. Both are right. Which one was wanted is the question you have to go and ask.
C
Different row counts in two tables
No. They have different GRAIN. One row of orders is one order; one row of order_items is one product on one order. Both tables are complete, and a total computed on the wrong one is wrong.
