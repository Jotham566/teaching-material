ENTRY AND EXIT DIAGNOSTIC: HOW TO USE AND SCORE
Ask the entry items orally in Session 1, before showing any explanation, and write down the learner's reasons in the learner's own words. Ask the exit items in Session 12 without showing the entry answers. The exit items change the facts and ask for the same understanding.
Score each item 0, 1 or 2. 0 = incorrect or unsupported. 1 = partly right, or right only after a prompt. 2 = independent, with a sound reason. Maximum 14. Record which ideas improved and which misconception remains. This is a comparison of explanations. It is not a certificate or a psychometric test, and one learner's scores cannot be compared with anyone else's.
Do not count terminology. A plain explanation in the learner's own words scores the same as a technical one.

WHAT A SCORE OF 2 CONTAINS
1 Entry / Exit. Arithmetic should be executed by a defined calculation tool or formula, and generation drafts text that still needs source and meaning checks. Exit: the learner assigns calculation to a calculation tool, drafting to generation, and names a source check for the memo.
2 Entry / Exit. Uploading or indexing does not by itself change model parameters; the file is supplied as context for the current request, or indexed for retrieval. Whether the provider keeps or uses it is a separate question about the account terms. Exit: the index and any derived chunks must be refreshed; the model weights need not change.
3 Entry. Models choose each next word from a range of likely options, so wording can differ between runs; difference in wording says nothing yet about whether either answer is right. Exit: the learner compares both outputs with the source clause, notes which omitted the carve-out, and does not choose the more fluent one.
4 Entry / Exit. The passage must exist, say what the report claims, come from the right authority and edition, and its speaker must be identified. A party submission is not a holding.
5 Entry / Exit. A rejection stops the send step. A changed recipient or changed field invalidates the earlier approval.
6 Entry / Exit. Enforced matter permissions, a named owner, tests that try forbidden queries, and a stop condition. Exit: do not expand while another matter is exposed; contain, investigate, retest and obtain an authorised restart decision.
7 Entry. Possible reasons: the passage was not in the context the model actually used (truncated, summarised or not retrieved); the model had the text but did not use it faithfully; the exception sits in a different section or schedule from the rule; the question did not ask for it. Check: ask for the exact passage with its location, then compare it with the original document. Exit: the learner gives two causes from the same list and a distinct test for each, for example ask for the exact passage and location; supply only the relevant section and see whether the answer changes.
