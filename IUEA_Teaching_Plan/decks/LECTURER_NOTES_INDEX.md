# Lecture slides and speaker notes

Each slide has its own explanation, teaching illustration and misconception guidance. Code slides include a line-by-line explanation. The `.md` companion contains the same notes for preparation away from PowerPoint.

Close and reopen an already open presentation to load the updated notes. Use **View → Notes** while preparing or **Slide Show → Presenter View** when teaching. Speaker notes are for the lecturer; the audience display shows the slide.
