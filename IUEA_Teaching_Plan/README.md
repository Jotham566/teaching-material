## The final ML project

Everything for the project is in [Weeks_08-12/Project/](Weeks_08-12/Project/README.md): the notebooks, the rehearsal, the grader,
the deploy scripts for the entry page and collection, the student briefs and the marking guide. The answer notebooks and the
revision coding guide are in `Weeks_08-12/Lecturer Guides/` on this computer only: they are kept out of the public repository.

## Private files

Student marks, identity records and answer keys stay on this computer. They are listed in the repository's `.gitignore`
(for example `Assessments/assessment_operations/private/`, `Assessments/test_operations/private/`, the gradebook, and
`Weeks_08-12/Project/grader_spec/`). Never move them outside those paths without updating `.gitignore` first.
