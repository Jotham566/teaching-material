# Week 2 setup and A2

Start with 00_START_HERE.txt in the extracted student ZIP. Read STUDENT_HOW_TO.md or IUEA_ML_Student_Setup_Guide.docx for the step-by-step account, Colab, GitHub and submission workflow. Read ASSIGNMENT_INSTRUCTIONS.md for your cohort’s exact files.

Use the browser upload route: download your finished notebook from Colab, then in your private GitHub repository choose Add file > Upload files. Create and download your own README.md. Upload exactly your completed notebook and your own README.md together through the A2 form; paste the repository URL in its field. The CSV belongs in the runtime and repository, not the form.

Repairs 01–04 and hello_engineering.py are classroom practice, not graded uploads. A1 and Quiz 1 are separate catch-up tasks alongside A2 and Quiz 2. Read WEEK1_CATCHUP.txt. Each quiz closes 24 hours after its own activation.

If access fails, keep local copies and notify the lecturer promptly. The form’s published deadline applies unless the lecturer announces a change.
