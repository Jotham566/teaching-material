## 1. Start

Open a blank Word or Google Docs document. No Python, Colab or GitHub is needed. Add your name, Student Registration Number and cohort.

## 2. Complete four sections

1. **Problem 1:** describe an engineering decision, its inputs and intended result, a possible data source and a limitation. Explain whether machine learning would help.
2. **Problem 2:** answer the same points for a different problem.
3. **Problem 3:** answer the same points for a third problem.
4. **My selected problem and dataset:** choose one and justify why the proposed data could answer its question.

Inputs are information used to make a prediction; the target is the result to predict. Propose the study—you are not asked to train a model.

**Marks (20):** problem framing 6; data and feasibility 8; judgement 6.
