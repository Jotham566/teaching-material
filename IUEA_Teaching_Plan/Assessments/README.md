# Assessments

Everything that sets, collects and marks IUEA work.

| Item | What it is |
|---|---|
| [Grading_Policy_2026-11-10.md](Grading_Policy_2026-11-10.md) | The current marks policy: how assignments, quizzes, Test 1 and the project make the final mark. |
| [Block_Assessment_Arrangement_2026-11-10.md](Block_Assessment_Arrangement_2026-11-10.md) | The current block assessment arrangement (older versions are in `../_archive/`). |
| [Assignment_Instructions_Index.md](Assignment_Instructions_Index.md), [Assignment_Submission_Links.md](Assignment_Submission_Links.md) | Where each assignment's instructions and submission form are. |
| `assessment_banks/` | The question banks and issued notebooks for assignments, Test 1 and the projects. |
| `student_guides/` | The guide each course's students read for each assessment. |
| `grader/` | The automatic grader, the gradebook script, the quiz forms and the identity tools. |
| `test_portal/` | The entry page and gateway used for Test 1 (the ML project reuses it). |
| `test_operations/`, `assessment_operations/` | Checklists and scripts for running tests and continuous assessment. Their `private/` folders hold marks and stay on this computer. |
| `test_revision/` | Revision packs for the tests. |
| `roster_template.csv` | The class list template. |
| `grade-submissions`, `reconcile-identities`, `review-identities` | Terminal shortcuts for grading a downloaded ZIP and checking student identities, for example `./IUEA_Teaching_Plan/Assessments/grade-submissions EXPORT.zip` from the repository root. |

The gradebook (`IUEA_ML_Gradebook_Semester1.xlsx`) and the by-hand grading notes are private and kept out of the public repository.
