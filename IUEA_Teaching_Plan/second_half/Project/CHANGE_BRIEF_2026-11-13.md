## Added later on 13 November: one real dataset for everyone
7. The project uses one real dataset, the same file for every student in all three cohorts (no A/B/C variants): the UCI Steel Industry Energy Consumption dataset (a steel plant in South Korea, 2018, 15-minute readings, about 35,000 rows). Question 1 predicts Usage_kWh; Question 2 is a high-load warning. The split is by month (training January to August, validation September to October, test November to December, opened once); group cross-validation uses months as groups. CO2 is excluded because it is calculated from the target. No invented errors are presented as real. The "results on your own file" item gets fewer marks, because everyone has the same numbers. The rehearsal uses a different target or another real dataset, so it is not the exam.
