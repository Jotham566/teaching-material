# Handbook

Rules and guides written by hand. The student-facing files are copied into both student ZIPs.

| File | For | What it holds |
|---|---|---|
| START_HERE.md | Students and parents | Laptop and pack setup, tools, how a session works, how to share your work, the first presentation. Blocks marked for one track are resolved when the ZIPs are packaged. |
| AI_USE_POLICY.md | Everyone | When AI tools are and are not used, and how help is disclosed. |
| AI_CODING_ASSISTANTS_LAB.md | Instructor, session 21 | The 20-minute supervised critique of a coding assistant's advice. |
| MODERN_AI_ORIENTATION.md | Instructor, session 23 | The optional 20-minute link from the project to modern AI. |
| HYBRID_DELIVERY.md | Learners, parents and the instructor | The weekly pattern for in-person and online classes, the online 90-minute clock, how a build task is returned, the tech check, safeguarding for under-18s. The parts marked for the instructor (engagement, when to say come in person, online setup) are removed from the student copy. |
| BUILD_LOG_AND_SHOWCASE.md | Everyone | The build log (with the optional Project corner line), the progress map and badges, show-and-tells, the parent showcase, feedback and the certificate. There are no tests or marks. |
| SHOWCASE_GUIDE.md | Instructor and students | What a great project shows, as a checklist with no scores. |
