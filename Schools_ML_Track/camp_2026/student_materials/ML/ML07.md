## Block A. Build a small table

pandas is a library for tables. Run the cell and look at the table it prints.

**Predict.** Predict how many rows and columns the table has. Write your guess on paper first.

```python
import pandas as pd
sales = pd.DataFrame({"item": ["Book", "Pen", "Book"], "units": [2, 5, 3]})
print(sales)
print(sales.shape)
```

**Run it, then compare.** The table has 3 rows and 2 columns, so shape prints (3, 2). The headers are item and units. import pandas as pd loads the library and gives it the short name pd. A table made this way is a DataFrame. The dot after sales reaches a property that belongs to that table.

**Investigate.**

1. What does the first number of shape count?
2. Where do the headers come from?

## Block B. Read the practice shop file

camp_shop.csv sits beside your notebook. Read it into a table and look at the first rows.

**Predict.** Predict how many rows camp_shop.csv has and which headers it shows. Write your guess on paper first.

```python
import pandas as pd
shop = pd.read_csv("camp_shop.csv")
print(shop.head())
print(shop.shape)
print(list(shop.columns))
```

**Run it, then compare.** The table has 60 rows and 5 columns, so shape prints (60, 5). The headers are sale_id, date, item, units and unit_price_ugx. read_csv reads the file into a DataFrame and head shows its first five rows. The unit of money is in the header: unit_price_ugx is in shillings.
