## Words for today

| Word | What it means | Think of it like this |
|---|---|---|
| operator | A symbol that tells Python which calculation to do. | The plus and minus keys on a calculator. |
| parentheses | Brackets that make Python calculate the inside first. | Doing the part in brackets first in maths. |
| comment | A line starting with # that Python ignores and people read. | A note written in the margin. |
| convert | Change a value from one type to another, such as text to a number. | Changing shillings into dollars before adding. |
| error message | Python telling you what it could not do and where. | A teacher marking the exact line you got wrong. |
| traceback | The list of lines Python followed before the error. | A trail of footprints that ends at the problem. |

## Block A. The basic operators

Run the cell. Notice the difference the brackets make.

**Predict.** Predict the four numbers before you run. Write your guess on paper first.

```python
price = 3000

```

**Run it, then compare.** The cell prints 12000, 750.0, 2000 and 5000. + adds, - subtracts, * multiplies and / divides. Multiplication happens before subtraction, so the brackets change the answer from 2000 to 5000. Brackets are called parentheses.

## Block B. Text becomes a number

A price arrives as text from a form. Run the cell and read the result.

**Predict.** Predict the output. Can Python multiply text by 4 and give 50.0? Write your guess on paper first.

```python
# The price came in as text
text_price = "12.5"
price = float(text_price)
total = price * 4
print(total)
```

**Run it, then compare.** The cell prints 50.0. float turns the text 12.5 into a number. The line starting with # is a comment, which Python ignores. If the text were abc, float would stop with a ValueError and the last line of the error would name the problem.

**Investigate.**

1. Which line of an error message do you read first?
2. What does float("12,5") do?

**Modify.** Change the text price to "20" and run the cell again.
