## Words for today

| Word | What it means | Think of it like this |
|---|---|---|
| comparison | A question about two values that answers True or False. | Asking whether your money is at least the ticket price. |
| Boolean | A value that is either True or False. | A light switch that is on or off. |
| if | Runs the indented lines below it only when its question is True. | If it rains, take an umbrella. |
| else | Runs when the if question was False. | Otherwise, leave the umbrella. |
| elif | Asks a second question when the first was False. | If it is raining take an umbrella, otherwise if it is cloudy take a hat. |
| indentation | Four spaces at the start of a line that show which instructions belong together. | Writing a sub-point under a heading. |

## Block A. A decision with if and else

A student has UGX 10000 and an item costs UGX 8000. Run the cell, then change the cost.

**Predict.** Predict the message that will print. Write your guess on paper first.

```python
budget = 10000
cost = 8000
if cost <= budget:
    message = "Within budget"
else:
    message = "Over budget"
print(message)
```

**Run it, then compare.** The cell prints Within budget. cost <= budget is a comparison and its answer is True, which is a Boolean. if runs the indented lines when the answer is True and else runs them when it is False. The four spaces at the start of the lines are indentation.

**Investigate.**

1. What is the answer to 5000 >= 5000?
2. What does = do compared with ==?

**Modify.** Set cost to 12000 and run the decision again.

## Block B. A rule that names a flower

The iris data records flowers of three species. Petal length helps tell them apart. Run the rule for one flower, then try the others on the table.

**Predict.** Look at the rule. Predict which species it names for a petal length of 4.7 centimetres. Write your guess on paper first.

```python
petal_length = 4.7
if petal_length < 2.5:
    guess = "setosa"
elif petal_length < 4.8:
    guess = "versicolor"
else:
    guess = "virginica"
print(guess)
```

**Run it, then compare.** The cell prints versicolor. elif asks a second question only when the first answer was False. Try the eight petal lengths. The true species are setosa twice, versicolor three times and virginica three times. The rule gets seven right and misses the 4.9 flower.

**Investigate.**

1. Which of the eight flowers does the rule get wrong?
2. How would you move the rule so that 4.9 is right?
3. What is the accuracy on these eight flowers?

**Modify.** Set petal_length to 4.9 and run the rule.
