## Block A. Lists and dictionaries

A tuck shop keeps three prices in a list and one product in a dictionary.

**Predict.** Predict what prints. Which number is prices[0]? Write your guess on paper first.

```python
prices = [1000, 2000, 3000]
product = {"name": "Juice", "price": 2000}
first = prices[0]
juice_price = product["price"]
print(first)
print(juice_price)
print(len(prices))
```

**Run it, then compare.** The cell prints 1000, 2000 and 3. Square brackets after a list give the item at that index, and the first index is 0. Square brackets after a dictionary give the value for that key. len counts the items in a list.

**Investigate.**

1. Why is prices[0] the first price?
2. What happens if you ask for prices[3]?

**Modify.** Print the last price using its index.

## Block B. A loop that adds

Run the loop and follow how total grows after each pass.

**Predict.** Predict the four numbers printed. Write your guess on paper first.

```python
prices = [1000, 2000, 3000]
total = 0
for price in prices:
    print(price * 2)
    total = total + price
print(total)
```

**Run it, then compare.** The cell prints 2000, 4000, 6000 and then 6000. for price in prices takes one item at a time and runs the indented lines for it. total starts at 0 and grows by the item each pass: 1000, then 3000, then 6000.

**Investigate.**

1. What is total after the second pass?
2. What goes wrong if total = 0 is moved inside the loop?

**Modify.** Change the list to [1500, 2500] and run the loop again.
