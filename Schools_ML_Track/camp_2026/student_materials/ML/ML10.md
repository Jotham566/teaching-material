## Words for today

| Word | What it means | Think of it like this |
|---|---|---|
| missing value | A cell with no recorded value. Its true value is unknown. | A blank in the price column. |
| duplicate | A row repeated exactly. It may be an accident or a real second sale. | The same receipt copied twice. |
| raw data | The file as you received it. Keep it unchanged. | The original receipt book. |
| cleaning log | A list of every change made and why. | The marking notes beside a corrected exercise. |
| to_csv | Saves a table into a CSV file. | Copying the register to a new page. |
| index=False | Tells to_csv not to write the extra row-number column. | Not copying the page numbers. |

## Block A. Count the problems

A tiny table has two sets of trouble. Count them before you change anything.

**Predict.** Predict how many missing prices and how many duplicate rows the raw table has. Write your guess on paper first.

```python
import pandas as pd
raw = pd.DataFrame({"id": [1, 2, 2, 3], "price": [1000, None, None, 3000]})
missing = raw["price"].isna().sum()
dupes = raw.duplicated().sum()
clean = raw.drop_duplicates().copy()
print(missing, dupes, len(clean))
print(clean["price"].mean())
```

**Run it, then compare.** The cell prints 2, 1 and 3, then 2000.0. isna marks each blank as True and sum counts them. duplicated marks the repeated row and drop_duplicates removes it. copy makes a separate table, so raw stays unchanged. The mean of 2000.0 uses the two prices that exist and ignores the missing one.

**Investigate.**

1. Why do we work on a copy?
2. Why not replace the missing price with 0?

## Block B. Save a cleaning log

Write down what you found as a small table and save it as a file.

**Predict.** Predict how many rows and columns the saved log has after you read it back. Write your guess on paper first.

```python
log = pd.DataFrame({"step": ["raw rows", "duplicate removed", "price still missing"], "count": [4, 1, 1]})
log.to_csv("cleaning_log.csv", index=False)
log_back = pd.read_csv("cleaning_log.csv")
print(log_back)
print(log_back.shape)
```

**Run it, then compare.** The log has 3 rows and 2 columns. to_csv writes the table into cleaning_log.csv. index=False stops pandas adding a column of row numbers. Reading the file back proves that it saved. The log lists the raw row count and each change, so a reader can repeat the cleaning.
