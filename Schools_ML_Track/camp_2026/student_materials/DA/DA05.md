## Block A. Lists and positions

The units of the first six sales in the shop table are 1, 2, 4, 7, 6 and 5. A list keeps them in order inside square brackets. Square brackets after a list name pick out one position. Position 0 is the first.

**Predict.** Predict what each print shows. Write your guess on paper first.

```python
units = [1, 2, 4, 7, 6, 5]
print(units[0])
print(units[3])
print(len(units))
print(max(units))
```

**Run it, then compare.** The cell prints 1, 7, 6 and 7. Position 0 holds the first value and position 3 holds the fourth. len counts the values and max finds the largest.

**Investigate.**

1. Why does units[3] show 7 and not 4?
2. Which position holds the last value?

**Modify.** Print the value at position 4.

## Block B. Dictionaries and a loop with a running total

A dictionary stores named pairs. A for loop repeats its indented lines for each value in a list. The name after for stands for the current value.

**Predict.** Predict the final total and the price of Pen. Write your guess on paper first.

```python
units = [1, 2, 4, 7, 6, 5]
prices = {"Book": 3000, "Pen": 1000, "Juice": 2000}
print(prices["Pen"])
total_units = 0
for u in units:
    total_units = total_units + u
print(total_units)
```

**Run it, then compare.** The cell prints 1000 and then 25. The loop starts the running total at 0 and adds each of the six values in turn: 1, 3, 7, 14, 20, 25.

**Investigate.**

1. What does the line total_units = total_units + u do?
2. What would happen if total_units = 0 sat inside the loop?

**Modify.** Change the loop to print each value plus 1 and then print the final total.
