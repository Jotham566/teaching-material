## Block A. Build a tiny table

pandas is a library for tables. import pandas as pd loads it and gives it the short name pd. A dot after a name reaches something that belongs to it: sales.shape asks the table for its size. A shape of (3, 2) means three rows and two columns.

**Predict.** Predict the shape of the table before you run the cell. Write your guess on paper first.

```python
import pandas as pd
sales = pd.DataFrame({"item": ["Book", "Pen", "Book"], "units": [2, 5, 3]})
print(sales)
print(sales.shape)
print(list(sales.columns))
```

**Run it, then compare.** The cell prints a table of three rows and two columns, then (3, 2), then ['item', 'units']. The first column holds the item sold and the second holds the units.

**Investigate.**

1. Which number in (3, 2) counts rows?
2. Where do the column headers come from?

## Block B. Read a CSV file

pd.read_csv reads a CSV file and returns a DataFrame. The path is where the file is. Here the file sits beside the notebook, so its name is enough. dtypes lists the type of each column.

**Predict.** Predict how many rows and columns camp_shop.csv has, and which columns hold text. Write your guess on paper first.

```python
shop = pd.read_csv("camp_shop.csv")
print(shop.shape)
print(shop.dtypes)
products = pd.read_csv("sunrise_products.csv")
print(products.shape)
print(products.head(3))
```

**Run it, then compare.** The shop table has shape (60, 5). date and item hold text. The other three columns are whole numbers. The Sunrise products table has shape (15, 5): fifteen products, each with an id, a name, a category and two prices.

**Investigate.**

1. Which columns would you use to work out revenue?
2. Why is date a text column here?
