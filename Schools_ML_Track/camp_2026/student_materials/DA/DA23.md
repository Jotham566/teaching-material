# DA23 Rehearse a five minute explanation

Week 8 | Session 23 of 24 | Data Analysis

## Before this lesson

Complete DA22 Write the report and package the evidence. If you cannot explain the previous example, use its repair cue with the instructor before moving on.

## Learning objective

By the end of this class: Explain a chart, its calculation and a limitation to a nontechnical listener in five minutes.

## Understand the idea

A parent should understand the question and the conclusion without knowing SQL. Explain a chart in ordinary language: what is compared, the unit, the biggest difference and the limitation. A demo is evidence that you understand your own work. After the project rehearsal, the instructor may use MODERN_AI_ORIENTATION.md for a 20-minute introduction connecting these foundations to modern AI. This replaces an optional second rehearsal; it adds no assignment or class.

## Follow the worked example

1. Read the example before running or typing it. Say what you expect to happen.
2. The instructor demonstrates it, explaining each new term. Follow one step at a time.
3. Compare your output with the expected result below. If it differs, use the repair cue.

Create five slides: question; data; analysis steps; most useful finding; recommendation and limitation. Show the chart report and one Python calculation or SQL query. Rehearse with a timer.

Expected result: A five-minute presentation, screenshot backup and peer feedback.

## When something goes wrong

If the demo depends on internet, save a local copy and screenshots before showcase day.

## Practise between classes

Spend 20 to 30 minutes repeating the worked example without copying, then change one input and predict the new result. Stop after 30 minutes if stuck, save the error or a screenshot, and bring the question to the next class. On project weeks use the same time to complete the stated milestone. Plan two 45 to 60 minute practice blocks on non-class days; leave time for rest and school work.
