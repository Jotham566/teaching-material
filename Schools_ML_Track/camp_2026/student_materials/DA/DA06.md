## Block A. A function and a check

A function starts with def. print only shows something on the screen. return sends a result back so other code can use it. A passing assert prints nothing at all. A failing one stops with an error.

**Predict.** Predict what the function returns for 3 units at 2000 shillings, and what a passing assert prints. Write your guess on paper first.

```python
def revenue(units, price):
    return units * price

print(revenue(3, 2000))
assert revenue(3, 2000) == 6000
assert revenue(0, 2000) == 0
```

**Run it, then compare.** The cell prints 6000. The two asserts print nothing, which means both pass. units and price are the parameters. 3 and 2000 are the arguments.

**Investigate.**

1. What is the difference between return and print?
2. What does it mean that the asserts print nothing?

**Modify.** Add a third assert that checks revenue(5, 1000) equals 5000.

## Block B. Edge cases and a guard

A share is a part divided by a whole. Dividing by zero is an edge case. A function can guard against it with an if before it divides.

**Predict.** Predict the result of share(12, 20) and of share(5, 0). Write your guess on paper first.

```python
def share(part, whole):
    if whole == 0:
        return 0
    return part / whole

print(share(12, 20))
print(share(5, 0))
assert share(12, 20) == 0.6
assert share(5, 0) == 0
```

**Run it, then compare.** The cell prints 0.6 and then 0. When the whole is zero the function returns before it divides, so no error appears.

**Investigate.**

1. Why does the function check the whole before it divides?
2. Is returning 0 for share(5, 0) always the right answer?

**Modify.** Add an assert that share(1, 4) equals 0.25.
