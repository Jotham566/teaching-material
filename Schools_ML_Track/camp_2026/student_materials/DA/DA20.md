## Learning objective

By the end of this class: Build a reproducible Python analysis with SQL evidence and a justified cleaning log.

## Understand the idea

Reliability means the reader can follow the steps from raw records to your answer. A cleaning log explains changes, including when none were necessary. Make one calculation at a time and compare it with a small hand-worked example.

## Follow the worked example

1. Read the example before running or typing it. Say what you expect to happen.
2. The instructor demonstrates it, explaining each new term. Follow one step at a time.
3. Compare your output with the expected result below. If it differs, use the repair cue.

Copy raw data into a protected working folder. Profile counts, types, missing values and IDs. Build three SQL queries and matching pandas summaries for your project questions.

Expected result: A saved Python notebook, SQL file and cleaning log with reconciled results.
