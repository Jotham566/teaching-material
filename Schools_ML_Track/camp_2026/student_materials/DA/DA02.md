## Words for today

| Word | What it means | Think of it like this |
|---|---|---|
| value | One piece of information, such as 2000 or Juice. | One entry on a receipt. |
| integer | A whole number with no decimal part. | Counting 3 books. |
| float | A number with a decimal part. | A price of 2500.5 shillings. |
| string | Text inside quotation marks. | A name written on a label. |
| variable | A name that points to a value. | A label on a box of stock. |
| type | The kind of value: integer, float or string. | Knowing whether a box holds pens or juice. |

## Block A. Names point to values

A shop sells 3 Juice bottles at 2000 shillings each. The equals sign stores a value under a name. The right side is worked out first.

**Predict.** Predict the three lines the cell will print. Write your guess on paper first.

```python
price = 2000
units = 3
revenue = price * units
print(revenue)
print(type(price))
print(type("2000"))
```

**Run it, then compare.** The cell prints 6000, then <class 'int'>, then <class 'str'>. price and units are variables. 2000 is an integer. The quoted "2000" is a string, which is text. The equals sign stores the value on its right under the name on its left.

**Investigate.**

1. Why is type("2000") a string?
2. What does the equals sign do in revenue = price * units?

**Modify.** Change units to 5 and run the whole cell again.

## Block B. Decimals and converting text

Prices can have decimals. Text that looks like a number has to be converted before Python can calculate with it. The words float and int convert text into those types.

**Predict.** Predict what each of the first three prints shows, and whether the last line will work. Write your guess on paper first.

```python
price = 2500.5
text_price = "2500.5"
print(type(price))
print(type(text_price))
print(price * 2)
print(float(text_price) * 2)
```

**Run it, then compare.** The cell prints <class 'float'>, <class 'str'>, 5001.0 and 5001.0. The quoted price is text. float() turns it into a number that can be multiplied.

**Investigate.**

1. Why does the answer 5001.0 keep a decimal point even though 2 is a whole number?
2. What would happen with float("two")?

**Modify.** Convert the text "1500" to an integer with int() and multiply it by 4.
