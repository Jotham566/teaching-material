## Words for today

| Word | What it means | Think of it like this |
|---|---|---|
| comparison | A question that gives True or False, such as units >= 5. | Asking whether a pupil is tall enough to ride. |
| Boolean | A value that is either True or False. | A light that is on or off. |
| if | Run the indented lines only when the condition is True. | Enter only if you have a ticket. |
| else | Run these lines when the condition is False. | Otherwise, go to the queue. |
| indentation | Four spaces at the start of a line show which lines belong to the if. | The inside of a bracket in a sentence. |
| and, or | and needs both conditions True. or needs at least one. | Entry needs a ticket and an ID. A discount needs a student card or a coupon. |

## Block A. Compare and decide

A comparison asks a question. == asks whether two values are equal. >= means at least. The word if runs its indented lines only when the answer is True. A colon ends the if line and four spaces mark the lines that belong to it.

**Predict.** Predict what prints for a budget of 4999, then for 5000, then for 5001. Write your guess on paper first.

```python
budget = 5000
print(budget >= 5000)
if budget >= 5000:
    print("Buy")
else:
    print("Save")
```

**Run it, then compare.** The cell prints True and then Buy. With a budget of 4999 the comparison is False and the cell prints Save. 5000 and 5001 both print Buy, because >= includes the edge value.

**Investigate.**

1. Why does 5000 print Buy?
2. What is the difference between = and ==?

**Modify.** Set budget to 4999 and run the cell again.

## Block B. Two conditions together

A large order needs 5 units or more. An expensive item costs 2000 shillings or more. and needs both to be True. or needs at least one.

**Predict.** Predict the answer for 6 units of an item at 1000 shillings, for both rules. Write your guess on paper first.

```python
units = 6
price = 1000
large = units >= 5
expensive = price >= 2000
print(large and expensive)
print(large or expensive)
if large and expensive:
    print("Large and expensive")
elif large:
    print("Large only")
else:
    print("Small")
```

**Run it, then compare.** The cell prints False, then True, then Large only. The order is large and not expensive, so and gives False and or gives True. elif means else if: it tests a second condition when the first is False.

**Investigate.**

1. Why is the answer to large and expensive False?
2. Which branch runs for 3 units at 2500 shillings?

**Modify.** Change the price to 2500 and run the cell again.
