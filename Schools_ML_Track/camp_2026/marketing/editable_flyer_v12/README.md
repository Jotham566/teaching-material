# School Track flyer — credentials edition

The portrait is replaced by a full-height navy credentials panel. Name, professional role, teaching affiliation, master’s and incoming PhD wording come from the organiser’s original reference. The audience, curriculum, outcomes, fee and booking information remain unchanged.

Canvas: 1024 × 1664. PNG: 2048 × 3328. The fee is UGX 1,000,000 per learner for groups of 1–5.

## Deliverables

- output/School_Track_Credentials_Editable.pptx: editable PowerPoint master.
- output/School_Track_Credentials.png: sharing image.
- output/School_Track_Credentials.pdf: A4 portrait with side margins, selectable text and contact links. No bleed.
- output/School_Track_Credentials.svg: vector document with embedded graphics and editable text.

Use PowerPoint’s Selection Pane to edit named text, panels and independent logo images. Fonts: Arial, Arial Black and Arial Narrow. Export fresh PNG/PDF files after editing; existing exports do not update automatically.

Source-based edits use source/layout.json and the included exporters with the Codex artifact runtime and ReportLab.
