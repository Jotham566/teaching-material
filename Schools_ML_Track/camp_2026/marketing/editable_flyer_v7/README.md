# School Track flyer — compact edition

The marked decorative lower section has been removed: books, desk, mug and repeated slogan. Eligibility is retained in one line below the fees and booking blocks. The blended actual portrait, learning content, outcomes, logos and contact information are unchanged.

Canvas: 1024 × 1664. Sharing PNG: 2048 × 3328 (about 16% shorter than the previous edition).

## Files

- output/School_Track_Compact_Editable.pptx: editable PowerPoint master.
- output/School_Track_Compact.png: sharing image.
- output/School_Track_Compact.pdf: A4 portrait PDF with side margins and contact links. No print bleed.
- output/School_Track_Compact.svg: editable vector document with embedded images.

Text and panels are native PowerPoint objects. Portrait, logos and icons are separate images. Use the Selection Pane to select named objects. Fonts: Arial, Arial Black, Arial Narrow and Caveat. Install assets/Caveat.ttf on another computer before editing. Keep photo proportions locked and QR square.

The portrait retains original RGB pixels and proportions; its grey background was masked and edges softened in the preceding edition. This revision does not change the portrait.

For source-based edits, edit source/layout.json and run the included exporters with the Codex artifact runtime and ReportLab. Export fresh images and PDF after editing the master: existing exports do not update automatically. See source/SOURCES.md and asset license files.
