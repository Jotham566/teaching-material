# ML23 Explain the project to a parent

Week 8 | Session 23 of 24 | Machine Learning

## Before this lesson

Complete ML22 Final test and reproducible handover. If you cannot explain the previous example, use its repair cue with the instructor before moving on.

## Learning objective

By the end of this class: Explain the project to a nontechnical listener in five minutes using five clear slides.

## Understand the idea

A presentation is a short explanation for a listener, not a list of library names. A claim needs a visible result and a limitation. Five minutes is enough for one question, one demonstration and one chart. Show only approved, non-personal data; publishing online is optional. After the project rehearsal, the instructor may use MODERN_AI_ORIENTATION.md for a 20-minute introduction connecting these foundations to modern AI. This replaces an optional second rehearsal; it adds no assignment or class.

## Follow the worked example

1. Read the example before running or typing it. Say what you expect to happen.
2. The instructor demonstrates it, explaining each new term. Follow one step at a time.
3. Compare your output with the expected result below. If it differs, use the repair cue.

Create five slides: my question; what data I used; what I built; result compared with baseline; limitation and next step. Rehearse a five-minute demonstration, then answer one question from a peer.

Expected result: A saved presentation and a timed rehearsal with feedback.

## When something goes wrong

If the explanation is mostly code, replace it with the question, a labelled chart and a worked prediction.

## Practise between classes

Spend 20 to 30 minutes repeating the worked example without copying, then change one input and predict the new result. Stop after 30 minutes if stuck, save the error or a screenshot, and bring the question to the next class. On project weeks use the same time to complete the stated milestone. Plan two 45 to 60 minute practice blocks on non-class days; leave time for rest and school work.
